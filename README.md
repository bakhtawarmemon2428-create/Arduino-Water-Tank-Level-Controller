# Arduino Automated & Manual Water Tank Level Controller with Fault Detection

An Arduino-based water tank level control system that supports automatic and manual pump operation while detecting tank-level conditions and possible faults.

## Components

* Arduino Uno
* L293D Motor Driver
* Float Switches
* Water Pump
* LEDs
* Jumper Wires
* Breadboard
* Power Supply

## How It Works

The float switches monitor the water level in the tank and provide input to the Arduino. In automatic mode, the Arduino controls the water pump according to the detected water level. Manual mode allows the pump to be controlled directly.

The system also uses fault detection to identify abnormal water-level or pump conditions and provide an indication when a fault is detected.

## Features

* Automatic water level control
* Manual pump control
* Float switch-based level detection
* Water pump control using L293D
* Fault detection
* LED status indication

## Technologies Used

* Arduino Uno
* C/C++
* L293D Motor Driver
* Float Switches
* Water Pump

## Project Purpose

This project demonstrates how Arduino can be used to monitor water levels and control a water pump automatically or manually while providing basic fault detection.
